# Mausritter: We Deal in Pips

![Portada de Mausritter: We Deal in Pips](assets/wdip-cover.webp)

Una frontera de ratones, pólvora y pips para **Foundry Virtual Tabletop**. Este módulo transforma la presentación de las fichas de Mausritter con una estética de cartel de recompensa y añade herramientas para partidas western: armas de fuego, consumo automático de munición y ayuda contextual dentro de la propia ficha.

## Funciones principales

- Estética western de papel envejecido para personajes, criaturas y hirelings.
- **AGI**, **HRT**, **LEAD**, **Agallas** y **PLOMO** integrados en la interfaz.
- Campos adicionales de **Edad** y **Ataques especiales**.
- Marcado de armas de fuego y consumo automático de 1 punto de Plomo al disparar.
- Avisos cuando un personaje se queda sin munición.
- Reparación automática de asignaciones antiguas de hoja que hayan quedado rotas.
- Mejoras de apilado, redimensionado, pestañas y lectura en fichas largas.

## Descripciones emergentes

La versión 1.5.0 permite consultar la información de la ficha sin abrir ventanas adicionales:

- Mantén el puntero durante **2 segundos** sobre un objeto para ver su nombre, imagen y descripción completa.
- Haz **clic derecho** para abrir la descripción inmediatamente y dejarla fijada.
- Pulsa `Esc` o haz clic fuera del recuadro para cerrarlo.
- También hay explicaciones rápidas en las características, recursos, inventario y notas.
- El visor conserva el formato de la descripción y admite enlaces enriquecidos de Foundry.

El sistema de ayuda no modifica el clic izquierdo ni el arrastre normal de las tarjetas.

## Requisitos

- Foundry VTT 12.
- Sistema [Mausritter](https://foundryvtt.com/packages/mausritter) 0.3.3 o compatible.

## Instalación mediante manifest

En **Foundry VTT → Add-on Modules → Install Module**, pega esta dirección en el campo **Manifest URL**:

```text
https://raw.githubusercontent.com/ManuRomera/mausritter-wdip/main/module.json
```

Después activa **Mausritter: We Deal in Pips** en la configuración de módulos del mundo.
